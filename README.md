# 📖 About Kripin

Kripin is a modern Personal Expense Tracker developed to help individuals manage their daily finances in a simple, secure and efficient way.

The application enables users to record income and expenses, monitor monthly budgets, analyze spending habits, generate professional PDF reports and gain valuable financial insights.

Kripin is designed with a clean user interface, PIN-based security, Progressive Web App (PWA) support and smart budgeting features to make personal finance management easy for everyone.

---

# 🎯 Vision

To simplify personal finance management by providing users with an intelligent, secure and user-friendly expense tracking solution that encourages better financial habits and smarter decision making.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Jiteshgiri/Kripin.git
```

## Open Project

```bash
cd Kripin
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Build Project

```bash
npm run build
```
